# RouteSearch 枚举预算截断 — 评估留档（2026-10-03）

> 性质：架构边界的详细评估，**不含实现**。按用户裁定（2026-10-03），
> 核心搜索逻辑的任何修改须先评估留档、经用户验收后才可启动实现。
> 本文证据全部来自当日只读实测（office.json 51 节点 / 60 场景）。

## 1. 机制现状

`RouteSearch.search`（src/capability_runtime/regression/route_search.py）：

1. 枚举所有层 span (start, end)；每个 span 用单调删除求**最大合法链**
   （`_max_chain`，多项式）；
2. 对 span 内逐层做**子集枚举**（`_enumerate`：每层 2^n−1 个子集的
   组合递归），收集满足覆盖 + 逐层全连接（`_interconnected`）的
   CandidateRoute，按工具数 Pareto 去重，上限 20 条；
3. 两道预算：`max_candidate_routes=20`（结果数）与
   `max_expansions=100_000`（子集检查次数，含被剪枝的）；
4. **见证回退**：枚举一无所获时，用 `_feasible_witness` 的最大链
   直接构造一条路线——可行性与预算完全解耦。

## 2. 实测证据（2026-10-03，office 域）

| 探针 | 结果 |
| --- | --- |
| 60 场景候选数分布（默认 100k 预算） | 0 条：9（未覆盖场景，设计使然）；2 条：24；3 条：14；4 条：13 |
| `_enumerate` 预算耗尽事件 | **246 次**（多 span × 60 场景；截断是常态而非例外） |
| 纯见证回退（恰好 1 条结果） | 0 次（截断前总能找到若干候选） |
| 预算放大到 5000 万 | **>28 分钟未完成**，中止——完全枚举空间不现实 |

结论：office 规模下截断普遍发生，但既有候选（2-4 条）+ 见证回退
使覆盖语义零损失。"加大预算"不是可行修法——空间本身是指数的。

## 3. 语义安全论证（为什么今天不是缺陷）

- **可行性判定**（`is_feasible` / `_feasible_witness`）只走最大链
  单调删除，不进枚举，与预算无关；
- **覆盖能力上界**（`covered_capabilities`）同样只依赖最大链；
- office 覆盖报告由种子见证路线线性推导（语义等价，见
  office-battlefield.md 批次 D 注记）——覆盖数字不受截断影响；
- 失败面被 fast 报告如实呈现（找到几条就是几条，不虚报）。

## 4. 实际受损面（为什么仍值得改进）

1. **候选多样性受限**：截断后只有"枚举顺序先碰到"的 2-4 条进入
   报告，非完备；
2. **最小性无保证**：逐层按字典序枚举子集，先找到的不一定是全局
   工具数最少的路线（层内 size 升序只是局部贪心）；
3. **下游放大**：`seeds export`（静态桥）从 fast candidate_routes
   里选链固化——候选池质量直接决定 basefast 种子质量，进而影响
   slow 回归的路线多样性与 rank 的证据面。

## 5. 改进选项

| 选项 | 内容 | 语义影响 | 风险 | 评估 |
| --- | --- | --- | --- | --- |
| C1 枚举重排序 | 层内子集按"覆盖未满足必需能力数降序、再字典序"生成，把预算花在高价值子集上 | 零语义变更（候选定义不变，完备枚举时结果集相同；只有截断场景下找到的候选不同）；小拓扑测试零影响 | 低：改动集中在 `_enumerate` 的子集生成顺序，确定性保持 | **推荐** |
| C2 迭代加深 | 按总工具数 k=1,2,3... 逐层加深搜索，天然最小优先 | 结果集语义不变（仍是合法候选），但搜索结构重写 | 中：`_enumerate` 重构 + 全部既有路线断言需回归 | 备选（C1 收益不足时） |
| C3 hitting-set 重构 | 把最小路线搜索形式化为分层命中集问题，用精确/近似求解器 | 可能改变候选完备性口径 | 高：核心算法换轨，需新验收文档 | 不建议现阶段 |

C1 与 C2 都不触碰宪法（Layer/provider/worker 决定边；搜索只是
在已声明边上找子图）。C3 属于算法架构变更，无必要不动。

## 6. 建议与验收口径（若用户裁定启动 C1）

- 验收基线：60 场景覆盖分布 42-9-9 不变（覆盖与枚举解耦的直接
  断言）；小拓扑既有 RouteSearch 测试零改动全绿（完备枚举下结果
  集不变的断言）；
- 正向断言：截断场景下找到的候选数 ≥ 现状（office 实测对比留档）；
- 确定性：同输入同输出（重排序规则全序、无随机）；
- 产物影响面：office fast 报告 / seeds 候选池可能变化，属预期内
  证据改善，需在批次文档标注。
